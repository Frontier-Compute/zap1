## Defect exposed by the run

The mempool path recorded the payment before the block path could create the
`PROGRAM_ENTRY` leaf. The block path then saw the payment as already handled.
The operator inserted that leaf manually for this run. Later scanner work
changed the payment lifecycle, but that later work does not rewrite this
historical test.
